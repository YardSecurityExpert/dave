The live test covered a model reply, an editable task proposal, cancellation, creation, and retrieval from Ambiguous.

  • ✓
    Featherless answers.

    The model runs through Dave’s local CopilotKit runtime.

  • ✓
    CopilotKit shows the review form.

    Edits are preserved. Cancelling creates no task.

  • ✓
